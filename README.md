# 冠军版与优化 A 盘后扫描

使用从 Bowen389/top 固定下来的 969 只股票名单、通达信日行情包和新浪沪深300日线。指数门控使用包含信号日的 MA20。技术候选按强度、涨幅和代码排序，指数门控关闭时仍展示技术候选。最近 60 个交易日不含信号日，停牌日留空，缺失窗口单独计数。

北京时间交易日 17:10 扫描，17:40 检查并补跑。Actions 可指定日期补扫。日报写入 reports/YYYY-MM-DD.md 和同名 JSON。

冠军版按买入日起再数两个交易日收盘退出，优化 A 在同一相对交易日开盘退出。报告记录这些执行参数，次日开盘仍须结合涨跌停、缺口和当前持仓核验。本包提供盘后信号与开盘待核验名单。
